# origin-web

**Cryptography that never leaves your machine.**

A client-side WebAssembly teaser for the [Origin cryptographic suite](https://github.com/KidIkaros/origin-tools). Every operation runs in your browser — no server, no account, no telemetry. Your keys are born in this tab and die with it.

🔐 **Live demo:** https://kidikaros.github.io/origin-web/

## The one rule

> No server ever sees your keys or plaintext.

This page makes **zero network requests** after the WASM module loads. Open devtools → Network tab and watch it stay empty. That's not a claim — it's a verifiable fact.

## What it proves

Four interactive scenarios, each demonstrating part of the Origin thesis:

1. **Identity in your browser** — Ed25519 keypair generation, signing, verification
2. **The envelope** — Passphrase → Argon2id → XChaCha20-Poly1305 encryption
3. **Shard a secret** — Reed-Solomon secret sharing (recover from any 3 of 5 shards)
4. **Entropy audit** — Shannon entropy, chi², bit bias analysis

All powered by [origin-crypto-sdk](https://github.com/KidIkaros/OriginSDK) compiled to WebAssembly.

## Architecture

```
origin-web/
├── crate/          # Rust wasm-bindgen bindings (Layer 2)
│   ├── Cargo.toml  # Depends on origin-crypto-sdk via git + [patch] for local dev
│   └── src/lib.rs  # Thin wrappers: bytes/hex in, bytes/hex/JSON out
├── www/            # Static site (Layer 3)
│   ├── index.html  # Four teaser scenarios + live network counter
│   ├── app.js      # Frontend glue + sovereignty banner
│   ├── style.css   # Dark technical aesthetic
│   └── pkg/        # Built WASM (gitignored, regenerated by build.sh)
├── build.sh        # wasm-pack build + stage to www/pkg/
├── DESIGN.md       # Full architecture doc (Phase 0-3 plan)
└── .github/workflows/deploy.yml  # CI: build + deploy to GitHub Pages
```

**Three layers:**
1. **SDK** (`origin-crypto-sdk` with `wasm` feature) — the real crypto
2. **Bindings** (`crate/`) — thin `wasm-bindgen` wrappers
3. **Frontend** (`www/`) — static HTML/JS/CSS served by GitHub Pages

## Build locally

```bash
# Prerequisites: Rust, wasm-pack, wasm32-unknown-unknown target
rustup target add wasm32-unknown-unknown
curl https://rustwasm.github.io/wasm-pack/installer/init.sh -sSf | sh

# Build (release mode, ~256KB wasm after wasm-opt)
./build.sh

# Serve locally
cd www && python3 -m http.server 8080
# Open http://localhost:8080
```

For fast iteration: `./build.sh --dev` (debug build, no wasm-opt).

## Deployment

Pushes to `main` trigger `.github/workflows/deploy.yml`:
1. Checks out `origin-web` + `origin-crypto-sdk` (sibling path dep)
2. Builds WASM with `wasm-pack`
3. Deploys `www/` to GitHub Pages

**Live at:** https://kidikaros.github.io/origin-web/

## Development notes

- **Local SDK iteration:** `crate/Cargo.toml` has a `[patch]` section pointing to `../../origin-crypto-sdk`. Edit the SDK locally, rebuild, see changes instantly. Comment out the patch for CI/clean builds.
- **WASM size:** 256KB after `opt-level=s`, `lto=true`, `wasm-opt`. The Phase 0 spike was 890KB — optimization cut it by 71%.
- **Browser compatibility:** Requires `WebAssembly.instantiateStreaming` (all modern browsers). Falls back to `WebAssembly.instantiate` if unavailable.
- **Zero network requests:** The frontend hooks `fetch` + `XMLHttpRequest` and counts requests. After WASM loads, the counter stays at 0 — verifiable sovereignty.
